# Roblox Game Pass Opener

Pequeña aplicación de Windows escrita en Python.

## Qué hace

1. Recibe una URL de Roblox.
2. Comprueba que el dominio sea Roblox.
3. Muestra una ventana de confirmación.
4. Abre la URL en el navegador predeterminado.
5. La compra queda completamente manual.

## Qué NO hace

- No inicia sesión.
- No guarda contraseñas, cookies ni tokens.
- No pulsa botones de compra.
- No realiza transacciones automáticamente.

## Ejecutar

Necesitás Python 3 instalado.

```bash
python main.py
```

En Windows también puede funcionar con:

```bash
py main.py
```

Tkinter viene incluido normalmente con la instalación estándar de Python para Windows.
